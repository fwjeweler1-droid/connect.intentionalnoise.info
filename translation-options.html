Browser translation choices

Translate a webpage. Know where your text goes.

All four browsers below offer built-in translation for supported webpages. Tap or click your browser to see how it works and whether translation happens on your device or on a provider's servers.

Privacy matters.

Translation is controlled by your browser, not by Connect. Chrome, Edge and Safari generally use online translation services for webpages; Firefox processes its built-in translations on the device. Using cloud translation on a webpage containing private messages can transmit page text to the browser provider. No browser preference is collected here.

Choose your browser

Google Chrome

Where: Google's online translation service

Service: Google Translate. Built-in webpage translation normally needs an internet connection.

How: Select Translate in the address bar or right-click the page and choose Translate to your preferred language. Manage languages in Chrome Settings.

Separate experimental on-device AI translation features are not the same as Chrome's regular webpage Translate command.

Google's instructions
Microsoft Edge

Where: Microsoft's online translation service

Service: Microsoft Translator. Built-in webpage translation normally needs internet access.

How: Select the Translate icon in the address bar or accept the translation prompt. Configure preferred languages in Edge Settings.

Use an up-to-date version of Edge. Supported languages and options vary by platform.

Microsoft's instructions
Mozilla Firefox

Where: On your device

Service: Firefox Translations. The language models download to the device; translation text does not go to Mozilla's servers.

How: Choose Translate page from the toolbar or page menu. Download the required language pair when prompted. Supported languages may differ on mobile.

Offline translation is possible after the needed language models are installed.

Mozilla's instructions
Apple Safari

Where: Apple's servers for webpage translation

Service: Safari webpage translation. Language detection happens on the device; Safari sends webpage contents to Apple when you request a translation.

How: Open Safari's page menu and choose Translate Website, if offered.

Supported languages and availability vary by device, country and region.

Apple's instructions · Safari privacy details

What about translating Connect messages?

Connect's optional message-translation control is separate from your browser's built-in full-page translator. It is offered only if the browser supports the required on-device Translator API and language pair. Otherwise, no Connect translation request is made.

Do not assume a browser's Translate webpage command stays local. Check the processing location above before translating sensitive text.

This guide explains browsers; selecting a browser here does not install, switch to, or activate that browser.
